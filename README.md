# Library POS System

A JavaFX + Spring Boot point-of-sale app for a small library/shop. UI is built with FXML, business logic uses Spring services/repositories, and data lives in MySQL/MariaDB (see `library_pos.sql`). Default UI language is Arabic (`messages_ar.properties`).

## Quick Start

### Prerequisites
- **JDK 21+**
- IDE (IntelliJ / Eclipse / VS Code)

### Option 1: Run via IDE (Recommended)
1. Open the project folder in your IDE.
2. Wait for Maven dependencies to import from `pom.xml`.
3. Run:
   - `src/main/java/com/library/pos/LibraryPosApplicationLauncher.java`

### Option 2: Run via Terminal
```powershell
mvn clean javafx:run
```
OR
```powershell
mvn spring-boot:run
```

### Option 3: Docker MySQL (shareable DB)
```powershell
docker compose up -d
$env:SPRING_PROFILES_ACTIVE="mysql"
mvn spring-boot:run
```

## Project Layout (What each file does)

### Root
- `README.md` — This file.
- `pom.xml` — Maven build file (dependencies, plugins, Java version).
- `docker-compose.yml` — Local MySQL container for shared/dev DB.
- `library_pos.sql` — MySQL/MariaDB schema + sample data.
- `mvnw`, `mvnw.cmd`, `.mvn/` — Maven wrapper (run Maven without installing it).
- `target/` — Build output (generated by Maven).
- `hs_err_pid*.log` — JVM crash logs (generated; safe to ignore unless debugging a crash).
- `.vscode/`, `.git/` — IDE + Git metadata.

### Java Source (`src/main/java/com/library/pos`)
- `LibraryPosApplicationLauncher.java` — Spring Boot entry point; launches JavaFX app.
- `LibraryPosApplication.java` — JavaFX `Application` that loads FXML, applies theme, sets locale, and shows the main stage.

#### Controllers (`src/main/java/com/library/pos/controller`)
- `LoginController.java` — Handles login screen UI and authentication flow.
- `DashboardController.java` — Main dashboard screen controller.
- `ProductsController.java` — Product list/add/update UI logic.
- `WorkersController.java` — Workers management UI (add/list workers).

#### Services (`src/main/java/com/library/pos/service`)
- `AuthService.java` — Authentication logic and current user handling.
- `ProductService.java` — Product CRUD and business rules.
- `SaleService.java` — Sales logic (create/update sales, totals, status).
- `UserService.java` — User/worker management logic.

#### Repositories (`src/main/java/com/library/pos/repository`)
- `ProductRepository.java` — DB access for products.
- `SaleRepository.java` — DB access for sales.
- `UserRepository.java` — DB access for users/workers.

#### Models (`src/main/java/com/library/pos/model`)
- `Product.java` — Product entity/model.
- `Sale.java` — Sale entity/model.
- `User.java` — User/worker entity/model.
- `Role.java` — User roles enum (OWNER/WORKER).
- `SaleStatus.java` — Sale status enum.

### Resources (`src/main/resources`)
- `application.properties` — Default Spring Boot config.
- `application-mysql.properties` — MySQL-specific config (use with `SPRING_PROFILES_ACTIVE=mysql`).
- `messages.properties` — Default UI strings.
- `messages_ar.properties` — Arabic UI strings (default locale).
- `css/style.css` — UI styling.
- `fxml/login.fxml` — Login view.
- `fxml/dashboard.fxml` — Dashboard view.
- `fxml/products.fxml` — Products view.
- `fxml/workers.fxml` — Workers view.

## Database Notes
- The SQL script is **MySQL/MariaDB** format. It will **not** run in SQL Server without conversion.
- If you need SQL Server, tell me and I can convert the schema.

## Troubleshooting
- **Port 8080 already in use**: change `server.port` in `src/main/resources/application.properties`.
- **Database import errors**: make sure you are using MySQL/MariaDB and the schema exists.
