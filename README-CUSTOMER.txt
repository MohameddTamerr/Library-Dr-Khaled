Library POS System - Installation Guide
=========================================

SYSTEM REQUIREMENTS:
-------------------
- Windows 7 or later (64-bit recommended)
- Java 17 or later (Download from: https://www.java.com/download/)
- Minimum 4GB RAM
- 500MB free disk space

INSTALLATION STEPS:
------------------
1. Extract all files to your desired location (e.g., C:\LibraryPOS\)

2. Files included:
   - LibraryPOS.exe          (Main application launcher)
   - pos-system.jar          (Application file - required)
   - README.txt              (This file)

3. Double-click LibraryPOS.exe to start the application

FIRST RUN:
----------
On the first launch, the application will:
1. Create a database file (library.db) in the application folder
2. Show an Activation Screen

ACTIVATION:
-----------
1. The Activation Screen will display your unique Machine ID
2. Click "Copy ID" button
3. Send this Machine ID to your administrator
4. The administrator will provide you with a License Key
5. Paste the License Key in the activation window
6. Click "Activate"

After successful activation, the login screen will appear.

DEFAULT LOGIN:
--------------
Username: admin
Password: admin

IMPORTANT NOTES:
----------------
- Do NOT delete the library.db file (it contains all your data)
- Do NOT delete the license.dat file (required for activation)
- Keep backup copies of library.db regularly
- The application runs on port 8080 by default

TROUBLESHOOTING:
---------------
1. If the application doesn't start:
   - Ensure Java is installed
   - Check if port 8080 is available
   - Run as Administrator

2. If you get an activation error:
   - Verify the License Key is correct
   - Contact your administrator

SUPPORT:
--------
For technical support, contact your system administrator.
