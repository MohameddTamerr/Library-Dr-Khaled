License Key Generator - Administrator Guide
==========================================

PURPOSE:
--------
This tool generates license keys for customer activation.

REQUIREMENTS:
-------------
- Java 17 or later

HOW TO USE:
-----------
1. Run the LicenseGenerator:
   - Double-click LicenseGenerator.jar
   OR
   - Open Command Prompt and run: java -jar LicenseGenerator.jar

2. The program will prompt you to enter the customer's Machine ID

3. Customer provides their Machine ID from the Activation Screen:
   - They copy it by clicking "Copy ID" button
   - They send it to you via email/message

4. Paste the Machine ID into the generator

5. The generator will display the License Key

6. Send the License Key back to the customer

7. Customer pastes the key in their Activation Screen and clicks "Activate"

EXAMPLE:
--------
Customer Machine ID: qCdJ9F+Ns1iSxGcrHxpfRKQmErIwXW13telQfxRpysI=
Generated License Key: XwKKbL7k4LyoM5GjATilUmdaQ2uH2bYsoryf7SgeMS4=

IMPORTANT NOTES:
----------------
- Each Machine ID generates a unique License Key
- The same Machine ID will always generate the same License Key
- License keys are hardware-locked and cannot be transferred between computers
- Keep this tool secure - only authorized administrators should have access

TROUBLESHOOTING:
---------------
If customer reports "Invalid License Key":
1. Verify you copied the full Machine ID correctly (no extra spaces)
2. Ensure customer is pasting the full License Key
3. Verify customer is on the correct computer
